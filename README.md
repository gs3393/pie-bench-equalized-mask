# pie-bench-equalized-mask

Data and code behind two notes on gs3393.github.io:

- *What "Background Preservation" Actually Measures in Image-Editing Benchmarks* — https://gs3393.github.io/notes/editing-benchmark-background-metric.html
- *Give Every Method the Same Mask* — follow-up (link added when published)

Five text-guided image-editing methods (FTEdit, FlowEdit, FlowAlign, DNAEdit, DirectEdit) on a 151-image subset of PIE-Bench with SD3.5-medium, under three mask conditions: no mask, the benchmark's ground-truth mask pasted back at every step, and pixel compositing. Plus a VAE round-trip "no-edit" reference and two FlowAlign checks (resolution; save-path normalization).

## What is here

| Path | Contents |
|---|---|
| `results/*.csv` | Per-image scores written by DirectEdit's unmodified `evaluation/evaluate.py`. Columns are `<condition>\|<metric>`; values are on the paper's reporting scale (Structure ×10³, LPIPS ×10³, MSE ×10⁴, SSIM ×10²). `nomask.csv`, `gtmask.csv`, `automask.csv` are DirectEdit's runs; `vaebound.csv` is the no-edit reference; `flowalign1024*_nomask.csv` and `flowalign_minmax*_nomask.csv` are the FlowAlign checks (`flowalign1024_nomask.csv` is the mis-scored first attempt, kept for the record). Background metrics are NaN for the 31 images whose mask covers the whole frame. |
| `results/paired_stats.txt`, `results/summary_multi.txt` | Paired per-image bootstrap differences and tie-averaged rankings, as printed by the scripts. |
| `runner/` | Everything that was run. `run_condition.py` (DirectEdit), `run_ftedit.py`, `run_flowedit.py`, `run_flowalign.py`, `run_dnaedit.py` each copy one upstream editing loop and add a mask-blending line; `maskutil.py` is the shared mask preprocessing (identical to DirectEdit's `prepare_mask`); `pixel_paste.py`, `vae_roundtrip.py`, `prepare_subset.py`, `prepare_masks.py`, `summarize_multi.py`, `paired_stats.py`, `rescheck_compare.py`, `make_figures.py`, and the shell scripts that sequenced the runs. |
| `figures/` | The three example figures used in the follow-up note, generated by `runner/make_figures.py`. |
| `subset/ids.txt` | The 151 PIE-Bench image ids. PIE-Bench itself is not redistributed. |
| `audit/` | An adversarial audit of the first version of the measurement report (gpt-6-astra, read-only), its prompt, and the resulting action list. The audit found the first 1024² check mis-scored and several overstatements; the notes follow the corrected scope. The FlowAlign save-path section was added after the audit and was not re-audited. |

## Reproducing

Pinned upstream commits (cloned unmodified; the runners import from them via `PYTHONPATH`):

| Repo | Commit |
|---|---|
| DirectEdit — https://github.com/Tr1stesse/DirectEdit | `26b04bf` |
| FTEdit — https://github.com/Pengchengpcx/FTEdit | `442ef0f` |
| FlowEdit — https://github.com/fallenshock/FlowEdit | `2620a93` |
| FlowAlign — https://github.com/FlowAlign/FlowAlign | `a48125f` |
| DNAEdit — https://github.com/xiechenxi99/DNAEdit_code | `436e5b4` |

Environment: Python 3.10, torch 2.6.0+cu124, torchvision 0.21.0, diffusers 0.32.2, transformers 4.57.3 (pin it: `>=4.57.3` resolves to 5.x and breaks diffusers 0.32.2), `stabilityai/stable-diffusion-3.5-medium` snapshot `b940f670`, fp16, one RTX A6000 per run. Hyperparameters are each repository's documented defaults; every departure from the official scripts (resolution 512², VAE encode `mode()`, save path, CFG-flag handling in DNAEdit, per-image reseeding in three runners) is listed in the measurement report and in the runner docstrings.

Sequence: `prepare_subset.py` → `prepare_masks.py` → `run_baselines_gpu{0,1}.sh` (and `run_all.sh` for DirectEdit) → `finish_baselines.sh` (pixel paste, evaluation, summary) → `paired_stats.py`. Get PIE-Bench from https://github.com/cure-lab/PnPInversion and place it as `PIE-bench/` first.
